# SoulCode — Avatar Inteligente 🐟

![SoulCode](assets/logo.png)

## 📋 Descrição

O **SoulCode** é um projeto desenvolvido para o **Challenge FIAP 2026** em parceria com a **SoulUp by Prospera**. 

Nossa solução implementa um **Avatar Inteligente** capaz de interagir com o usuário de forma contextual e personalizada, sugerindo ações sustentáveis, acompanhando missões e aumentando o engajamento na plataforma.

---

## 🚀 Tecnologias Utilizadas

- CSS3
- JavaScript
- Python
- Java
- Oracle Database
